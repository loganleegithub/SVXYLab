# SVXYLab v0：联合研究实施规格

**版本：2026-09-07。当前状态：P0—P7及N1已验收；本轮授权M2机制诊断D1—D4，详见第15节。D5需单独决定；未获资本使用授权。原P7冻结规格副本保留。**

本规格是针对 SVXY 的独立设计；不是附件晴雨表的复刻。参数是为了把第一轮研究限定成可检验实验而预先选定，不是最优值。用户不需要解释每个统计细节，但必须能检查数据、账本与结论。

## 1. 第一轮明确要回答的问题

在实际 SVXY -0.5x 制度下，利用当时可得的期货曲线、隐含波动期限、压力变化、已发生波动和价格路径，联合模型是否比不看这些联合状态的办法提供更好的未来五日收益/损失信息？这部分信息能否在明确的成本与延迟下改善 SVXY/CASH 持仓？

不要求每个指标单独产生正收益，不要求某个模型每年获胜，不要求穷尽所有因子。要求全程不前视，并把失败定位到数据、预测还是经济映射。

第一轮只研究 SVXY 与现金，不加入 VXX、UVXY、期权、做空股票、借贷和自动交易。目标资产只能在账户权重 0～100% 之间；100% 是研究模型允许的上界，不是建议用户实际满仓。

## 2. 信息家族与来源边界

FEATURES.json 是特征字典：A～F 六个核心家族共 19 项，G 家族 SKEW 两项是首个扩展。各项为待检验的工程定义，不叫“有效因子”。

P3 实现口径：沿完整股票交易日索引先截断 2019 年起点，再做滞后与窗口运算。D01 用 5 个对数回报，D02/D03/F04 用 21 个对数回报（需 22 个 TR 水平）；F02 用含当日在内的 21 个 TR 水平。窗口不全保持缺失，D03 分母为零也保持缺失；A04 明确保存当前前月同一合约在 t 与 t−5 两端的结算与原件。公式及实验参数没有改变。

P3 保存全部冻结日期的原始未标准化特征；相关性只描述 2019–2023 完整共同日期的信息重叠，核心与加 SKEW 分开报告样本。三个状态卡日期在计算前记录，不按后来收益选择；不计算独立因子收益、不筛列、不拟合模型。实现和展示约定见 runs/p3/experiment_record.json，交付见 reports/features.html。

## 3. 数据产品：先可核对，再称“取得”

### 3.1 请求范围与资产

本轮数据请求与研究样本统一从 2019-01-01 起，至 P1 冻结时最近一个共同完成交易日。用户于 2026-09-07 因 SVXY 在 2018 年发生目标倍数变更而确认此起点；变更前值与原因保存在 runs/p1/experiment_change.json。请求范围不是保证可用范围。核心需要：
- 标准月度 VX 逐合约的日期、合约标识、真实到期日、结算价；保留可得的 OHLC、成交量、OI，但后两者暂不进模型。
- VIX、VVIX、VIX9D、VIX3M 的官方日值。
- SVXY 和 SPY 的原始 OHLCV、拆分、分红、总回报计算所需字段。
- SKEW 仅扩展；没有不影响六家族核心研究。

先选定一种正式 ETF 数据来源完成适配，不同时维护多个供应商后端。S13 是优先核实的接口候选，但需要付费权限；只有确实需要购买并核实具体覆盖后才让用户决定。已有合法数据优先使用。未经验证的免费网页价只可用于抽查。

P1 实际选择：Cboe 官方指数 CSV、标准月度 VX 目录及逐合约原件；ETF 使用 Yahoo Chart 原始响应，经 yfinance 1.7.0 获取，明确请求拆分、分红与资本利得事件。已核对两只 ETF 2019-01-02 至 2026-09-04 各 1930 日覆盖、OHLCV 关系和实际拆分。Nasdaq 与 QuantConnect 仅作参考核对，源间差异保留，不作为多个正式后端混合拼接。来源决策、失败原因和用户个人研究授权记录在 runs/p1/source_decision.json，具体覆盖见 reports/data.html。

### 3.2 日线表不是只剩 date/value

记录至少包含 `as_of_session, source, source_symbol, value, retrieved_at, availability_policy, raw_file`。若掌握真实发布时间，再记录 `published_at`；不知道不能填造时间。市场日期、实际发布时间、这次下载时间是三回事。

下载原件放 data/raw；清洗结果放 data/clean。只读保留原件，记录摘要和源地址即可；不建通用数据血缘服务。数据可以本地缓存，不要求每次回测重新下载。

### 3.3 期货合约选择

F1/F2/F3 是 t 收盘时尚未到期的标准月度 VX 合约，按官方到期日排序。不可把周合约、VXM、TAS 价格或日期重复项混进去。缺失一个应有近月合约时，不能把次近月自动改称近月。结算日收盘已到期合约不再作为 F1。

A04 使用 t 时的同一个前月合约在 t 和 t-5 的价格；不能计算后复权连续合约的伪收益。到期日直接核对官方合约信息，不只套“每月第三个星期三”。

CFE 结算价与期权隐含指数的日收盘值可能不是完全同步观测。保留价格类型/观察时点；A03 是日频基差代理，不冒充可执行的同步套利报价。

### 3.4 SVXY 制度与收益

S01 明确：2018-02-27 收盘后每日目标由 -1x 改为 -0.5x。该制度生效日期是历史事实；本轮统一选择 2019-01-01 为数据与研究起点，不使用 2018 年及以前的数据进入研究计算。主研究仅用新制度实际 SVXY；旧制度不能把日收益乘 0.5 就当作今天产品的真实历史。

所有输入的特征预热、回看窗口、训练样本和目标都只使用 2019-01-01 起的数据；窗口不足时保持缺失，待窗口自然成熟。SVXY 的 F03/F04 同样遵守此边界。若供应商只能提供包含更早日期的完整原件，原件照常只读保留，但研究输入按本轮起点截取，更早记录不用于预热或训练。

总回报由原始价格、拆分和分红交叉核验。不要把复权收盘与未复权开盘/最低价混除。首版所有目标使用收盘总回报路径，不声称捕获日内最大损失。实际基金回报已经含基金层费用，不能再重复减一次管理费。

P1 字段口径：Yahoo 的 quote OHLCV 已拆分调整，即使 auto_adjust=False。`provider_*` 列逐值保留供应商响应；`open/high/low/close` 乘该日之后已报告的拆分份额倍数，`volume` 除同一倍数，明确标为复原到当时份额单位的派生字段。供应商 `adjclose`、拆分与现金分配事件另列保留。后续 P2 必须使用一致的价格与份额口径；P1 未建立整段总回报或持仓账本。源间收盘和成交量差异、供应商精度及历史发布时间假设均如实披露。

### 3.5 缺失值与研究覆盖

主预测不把缺失近月价格用 VIX3M/VIX 替代。不跨长缺口填数据，不用未来值修补，不默默删除危机窗口。

特征无法取得：该日无新预测，报告缺失项；持仓模拟沿用前一仓位的实际持有状态，不跳过该日收益，也不临时调用 LLM 补判断。起始无仓位时为现金。必须报告失去预测服务的日期与期间盈亏。

SVXY 价格本身缺失：该段净值无法确认，不插值制造绩效；先补数据，否则只报告明确的连续可验证区间。报表其他事实仍可以显示，不把整个应用永久锁成 UNKNOWN。

## 4. 决策时钟：先固定，再建标签

以美国股票交易日 t 为信息日：
1. 只用 t 日及以前的完成数据。
2. t+1 日官方股票收盘前 60 分钟冻结决策；正常交易日为美东 15:00，半日市按实际收盘时刻减 60 分钟。
3. 模拟在 t+1 日官方股票收盘换仓，并扣成本。
4. 该次五日标签从 t+1 收盘以后开始，到 t+6 收盘结束。

即使 t+1 盘中已有新行情，本版也不用，以免悄悄变成不同信息产品。已持有头寸在 t+1 换仓前的损益仍归旧仓位；不能回避信息形成到执行之间的隔夜/白天损失。

历史文件多数没有当年的精确发布时间。主研究明确使用“假设次交易日截止前可得”的可用性约定，不宣称恢复了完整历史 PIT 数据库。额外将所有信号再延迟一个交易日做敏感性。今后每日采集开始保存真实收到时间，形成可审计前向记录。

收盘价只是模拟成交代理，不是实际可成交保证。没有自动报单、没有停损保证、没有盘中即时撤退能力。

## 5. 三个明确预测目标

记 `a=t+1` 为入场/调整仓位的收盘时点，`TR` 为核对过的 SVXY 总回报财富序列：

`R5 = TR[a+5]/TR[a] - 1`

`L5 = max(0, max_{k=1..5}(1 - TR[a+k]/TR[a]))`

`Y10 = 1{L5 >= 0.10}`

输出：
- μ5：未来五日持有 SVXY 的平均总回报估计。
- Q90(L5)：未来五日“相对当前入场点、在每日收盘观测”的最差损失的第 90 百分位估计。
- P10：同一期间这种损失达到 10% 的事件概率估计。

L5 不是期间峰谷最大回撤，不是盘中最低价，不是跌停可退出价。Q90 不是最大可能损失，P10 不是市场指数分位。

只有到 a+5 收盘已经发生，整行标签才成熟。未来结果没有发生的日报不能补零算准确率。标签事件阈值和期限只使用配置中这一组，不并行搜索 E5/E10/E15/E20 后挑最漂亮的结果。

## 6. 联合模型：三个初始对照，六个交互

### M0：不看特征的条件基准

使用同一当时训练窗口的历史平均 R5、L5 的 90% 分位以及事件率。事件率固定用 Jeffreys 平滑 `(positive_count+0.5)/(n+1)`；分位采用成熟库默认线性插值并记录版本。按同样时钟更新。这是模型是否真的区分市场状态的最低对照。

### M1：带收缩的线性联合模型

19 项特征一起输入。μ5 用 Ridge；P10 用 L2 LogisticRegression；Q90(L5) 用 QuantileRegressor(q=0.9)。均通过成熟库实现。不要 SMOTE、不要正类平衡后直接称校准概率。

### M2：非线性主效应 + 六个预定义交互

19 项输入各自用小型二次样条（3 个训练样本分位节点，knots="quantile"，不含冗余 bias），再加 FEATURES.json 中 I01～I06 六个标准化乘积。使用与 M1 相同三个预测头。这个设计允许状态依赖，但避免生成 171 个两两交互或穷举全部技术指标。

StandardScaler、样条节点、交互列的尺度均仅由当时训练部分拟合。样条使用线性外推；报告超出训练支持范围的输入，不偷偷截去历史尾部。不要把系数绝对值或 SHAP 排名称为因果权重。

P4 实现约定（首次真实拟合前已记录）：M1 对原始19列做训练期 StandardScaler；M2 先标准化原始19列，生成57个样条基及6个标准化输入乘积，再对这63列用训练期 StandardScaler 固定尺度。QuantileRegressor 使用该库的 L1 正则，LogisticRegression 为 L2；具体网格仍为 experiment.toml 原值。M0 的分位明确为 numpy.quantile(method="linear")。各期训练尺度、节点、系数和截距保存在普通JSON，不以全历史统计替代。

分位回归的原始输出可能越出合法损失范围；发布与持仓使用的 Q90 固定投影到 [0,1]，同时保存原始预测和投影次数，不能用截取掩盖模型失配。三类模型和所有内外层评分采用同一预先规定的处理。R5 的均值预测下界固定为 -1；概率由 logistic/常数头自然限制在 [0,1]。非有限数属于计算失败，不能填为零。

M2 中参数在一个月内固定，但某个指标的边际作用会随着交互变量变化。每月重估参数进一步容许缓慢变化。无需先建 HMM、状态聚类或大模型日常调权。

### M3 与 G 扩展：不是首轮前置

P6 可分别检验 M3（M2 + 504 交易日半衰期的历史样本权重），以及 M2+G01/G02。两者不能同时改变后只报告一次收益。

M3 的加权样本权重归一化到和为训练行数，避免无意改变正则力度；同样年度内层选超参数。SKEW 版本与核心版必须在相同可用日期比较。两种挑战者失败，不回头否定已完成的数据/程序。

## 7. 参数如何估计、多久更新

配置值在 experiment.toml。主训练最长过去 1260 个交易日，首次至少 400 行完整成熟样本；内层最少 200 行。从 2019-01-01 起积累样本。initial_train_end=2019-12-31 是最早候选训练截止，outer_test_requested_start=2020-01-02 是请求评估起点，两者不保证届时能拟合或预测。仅 2019 年的数据不足 400 行，实际首次预测必然晚于 2020 年初；程序须随时间继续积累当时已成熟的数据，直至满足全部内外层训练与标签条件。实际首个可预测日由可用数据与成熟条件决定，不使用 2019 年前数据或降低样本要求来提前预测。

这意味着最早期样本尤其薄弱；19 项特征与相邻重叠五日标签不是大量独立事件。报告每期训练行数、正例数、事件簇数、有效覆盖，不能声称初期崩盘概率已精确。

每月首个符合条件的决策时点重估系数；首次和此后每年第一次拟合，利用训练期内部末尾三个 63-session 验证块选择正则强度。候选网格见配置，各预测头分别根据其预测损失选择，不用账户夏普来挑特征系数。

- μ5 选均方误差。
- P10 选对数损失，另外报告 Brier 和校准。
- Q90 选 0.9 分位 pinball loss，另外报告分位覆盖。

每个内层训练集清除标签结束时间越过该验证块首个决策截止的样本。不能只用随机划分；也不能以为简单固定 gap 总能替代标签时间检查。

P4 时间与评分实现约定：最多1260个完整股票交易日窗口以信息日t为末端，再筛特征已可得、标签 label_matures_at<截止且 label_available_at<=截止的完整行。内层在这个窗口最后一个可用训练信息日以前，沿完整股票日历取末尾三个63-session块；不压缩缺失日，每块变换只拟合该块清除后的训练部分。候选按所有验证行损失平均，差<=1e-12视为数值并列而优先更强收缩。年度选参和月度重估以决策日的年/月为准。

并列时优先更强收缩。模型无正类/全正类等可预见小样本情况使用事先规定的常数基准并标记，不制造看似精确的 Logistic 拟合。不为概率添加又一层自由搜索的校准器；先展示未经额外校准的可靠性结果。

## 8. 历史评估协议

### 8.1 逐月走时序

对每个历史月：只让当时已成熟数据进入拟合→保存模型/预测→后来评分→下一月按原程序继续。未来整段标准化、全历史选阈值、先看全部危机再标状态均禁止。

允许在线程序消化早先测试月份已经成熟的结果；这是既定滚动更新，不是未来泄漏。禁止人类看过该测试块结果后改程序，再把同一块称为首次测试。

### 8.2 历史开发与封存段

2020～2023 作为请求的历史开发诊断段，实际预测评分从满足全部训练条件的首个可预测日开始，之前的无预测日期及原因照实报告；2024 年至 P1 冻结日作为本轮实现的封存历史段。主规格、变量、模型与政策完成后一次揭示。由于这些年份可能已被人类/之前研究看过，只称“本轮未参与选择的历史评估”，不称绝对未见数据。

### 8.3 不用一个总分掩盖结果

预测：每个目标的损失相对 M0、按年份/连续区间的差异、概率校准、分位覆盖、风险分层排序。概率图分 5 组并给实际样本与事件数；不夸大小数精度。

经济：CAGR、最大收盘回撤、最差单日/五日收益、平均与分布敞口、换手、交易成本、现金占用、避免/错失的主要路径。收益、回撤和暴露必须同时呈现。

用配对时间块 bootstrap（21 日，63 日敏感性，1000 次）描述指标差异的不确定性；不能按独立日假设显著性，也不能宣称该区间涵盖了所有研究选择不确定性。

## 9. 从预测到持仓：固定一个可审计翻译层

模型参数从数据学习；资本风险预算不是市场事实，必须另行设定。这里使用研究默认预算 B=5%、单边成本 c=5bp、模拟资本 100000 美元，均非真实交易建议。5bp 的小数值为 0.0005；费用/概率/波动单位需明确，禁止百分数与小数混用。

基本风险容量：
`Lhat = max(0, Q90(L5))`
`w_risk = 1 if Lhat == 0 else min(1, B/Lhat)`

主研究仓位：
`w_target = w_risk if mu5 > 2*c else 0`

现金为 `1-w_target`。这是一条预先限定的“收益筛选 + 损失分位预算”规则，不是最优效用解。2c 是保守的五日往返成本筛选，不能冒充真实动态交易总成本；实际交易成本仍逐笔扣除。

同时报告 risk-only 控制器 `w_target=w_risk`，检验预测平均收益的过滤是否有增量；不在两者中看完历史后悄悄只保留赢家。

Q90 预算不是最大损失保证：估计可能错、约 10% 的分位尾部仍可超出、实际每日再平衡路径也不同于单一五日固定头寸。不能标成“最大回撤 5%”。

只做日频计划换仓。没有日内止损，没有无限频率调仓，也没有突然增设的上涨/下跌状态手工覆盖。

### 9.1 自融资账本

旧持仓先经历执行日截至收盘的价格变化，再进行换仓。成本按执行前实际权重/持有数量与目标的差异计算，不按相邻目标之差偷算换手。目标权重定义为扣费后的实际资产权重。令换仓前净值为 E、实际 SVXY 权重为 u、新目标为 w、单边费率为 c：
- 买入或不变（w>=u）：换仓后净值 `E_new=E*(1+c*u)/(1+c*w)`。
- 卖出（w<u）：`E_new=E*(1-c*u)/(1-c*w)`。
- 新 SVXY 市值为 `w*E_new`，成本为 `c*abs(w*E_new-u*E)`。

这是按单边成交额比例扣费的自融资精确式，写可手算单元测试。c 是包括手续费/滑点的统一研究代理；不再重复扣另一份同义滑点。

初始研究现金 100000；份额允许小数只是回测近似。真实仓位需要股数/委托层，v0 不声称实现。主现金收益固定 0；这是比较约定，不是用户券商实际利率。可另报短债基准，但未经用户数据/账户核实不能当作已赚现金利息。

任何利润/亏损都连续记账；不能在 5 日重叠标签上各建一笔满仓交易再加总，造成隐性杠杆。模型每日给一个目标，账户只有一条连续净值。

P2 实现约定：首个信息日收盘建立现金锚点，最早在下一真实交易日收盘换仓；末日按市值计价，不强制清仓。无新目标时保留份额（遇拆分调整）和现金，不把昨日目标再次平衡。总回报中的现金分配按除息日确认并在收盘再投资；不冒充实际支付日期，本段 SVXY 无现金分配。首日未知回报与尚无完整未来路径的标签保持空。标签分别保存终点收盘成熟时间和次一交易日截止的假设可用时间。

### 9.2 必需对照与敏感性

对照包括现金、固定 25/50/75/100% SVXY 仓位、简单 F2>F1 时持有否则现金，以及 M0/M1/M2 经同一映射后的结果。固定权重再平衡也扣成本。

平均敞口匹配可以作为事后归因诊断，须明确不是当年事先可知的可交易权重。不能仅因模型平均仓位低就把回撤改善归功于识别能力。

固定成本 0/5/15/30bp 和预算 2.5/5/10% 为单因素敏感性；保持其他条件不变，不做全组合择优。再测额外一交易日延迟。毛收益用于诊断，净收益是主经济结果。

## 10. 信息家族的贡献

对 A～F 分组删除并重新训练，删除相关交互；比较共同日期的预测和经济增量。E 由 B/D 派生，不能宣称它提供独立数据源。

至少另做 B+D+E 联合删除的依赖诊断，以免删去 B 却通过 E 保留其关键变换，产生“B 无用”的错误结论。每个消融清楚写“删除列”还是“删除整个原始信息来源”。不只看系数/重要性排名。

相关家族可能互相替代；消融为诊断，不是因果证明。不要只汇报最好一次消融。

## 11. 工程实现范围

一个 Python 包、一份配置、一份特征字典、本地 CSV/JSON、一个 HTML 报告。优先 numpy/pandas/scipy/scikit-learn、一个成熟交易日历库、普通 pytest；有必要才补 requests/绘图/模板工具。锁定实际可安装版本，不要求用户安装 IDE、Docker 或手写终端命令。
