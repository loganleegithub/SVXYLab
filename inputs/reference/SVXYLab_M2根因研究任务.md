## 已知实现事实，不得误称为新发现

- 收益均值头用 Ridge 的平方误差加 L2 正则；P10 用逻辑回归；Q90 用非对称 pinball 损失加 L1 正则。不是三个头都使用 MSE。
- 主映射只读 mu5 和 q90，P10 不参与交易。
- 信号基于 t 及以前的数据，t+1 收盘执行；R5/L5 是该执行之后五个日收盘的目标。不能把原本正确的标签对齐写成 off-by-one bug。
- w_risk = min(1, B/q90)，q90=0 时为1；mu5 <= 2c 时主映射为0。原参数 B=.05、c=.0005。
- 五日标签与每日再决策不同；这是待检验的控制设计，不是自动判定的程序错误。
- P4 候选参数全部选择最强收缩端是已有结果。需核对 P4 收尾是否已区分严格改进与并列；复用已有诊断，勿重复生成同一结论。

## D1：把预测错误与映射放大分开

### 输入

现有同日期 M0/M2 预测、训练/拟合身份、实际连续账本及完整价格路径。不重新拟合模型，不使用未来结果决定哪天交易。

### 操作

1. 形成决策级账本，包含：信息日、原始特征、mu5、q90_raw/q90、p10、当期拟合身份、实际旧仓位、目标仓位、可执行时点、当期损益与后续已成熟目标。
2. 对全部切换分解：收益门槛跨越造成的目标变化、q90变化造成的风险容量变化、仅持仓价格漂移造成的再平衡。非线性相互作用保留，不强行声称存在唯一可加根因比例。
3. 在原映射、原资本、原成本和共同执行起点下比较四个固定组合：
   - mu_M0 + q_M0；
   - mu_M2 + q_M0；
   - mu_M0 + q_M2；
   - mu_M2 + q_M2。
   已有两条 risk-only 继续保留。上述组合是部件替换诊断，不是新策略晋升。
4. 统计切换前的 mu5-2c 距离、切换后的仓位幅度、持仓持续时间、月度模型更新日附近变化、不同头之间的逻辑冲突。门槛邻域的刻度在查看新增结果前记录，只作诊断、不择优。
5. 区分均值估计不确定性与未来收益的预测残差；不能拿整体 RMSE 直接当成 mu5 标准误。

### 输出

报告哪个预测头、哪个映射环节对损害有可复算贡献；若部件交互使结论不能唯一分配，明确说明。输出不是“这几个混搭里哪个回测最好”。

## D2：信号时效与持有期限

1. 把收益按原时钟拆开：信息完成到原执行之间的前置段、执行后第一日、执行后其余四日，以及原五日整体。使用对数收益做可加路径分解；账户仍按真实复利核算。
2. 检查原预测排序、门槛两侧与这些路径段的关系，按连续时期报告。前置段只用于诊断原程序错过了什么，不计为可实现收益。
3. 同一信息时点的原五日预测，不自动等于下一日预测。以五个固定起始偏移分别构造不重叠的五日持有诊断账户；每个偏移独立、各自100%资本上限，不把五条账户相加成杠杆。用相同偏移对照，并展示敞口、成本和时期差异。
4. 检查一日、五日变化与21日波动窗口的反应顺序；区分压力仍在上升和已经下降但水平仍高。不得事后用未来峰值给入场状态贴标签。
5. 更早执行只有在逐项确认数据在那个时点可得，且有一致价格/公司行动处理后才可进入可执行比较。否则只能列为不可交易的时效上界诊断。不得用当日完整收盘数据按当日收盘成交。
6. 若改为次日开盘或其他时点，新的训练标签、成熟时间、模型选择和执行价格必须整体重建；不能仅将旧预测提前成交后宣称原模型获救。本轮 D2 先不执行这个新系统。

### 输出

分别回答：信号是否主要在解释已发生的行情；原执行后的何种期限仍有条件信息；是否有证据支持时延耗尽信息；是否有证据支持五日预测与每日执行不匹配。不能仅凭一轮暴跌与反弹确定全局半衰期。

## D3：尾部、样本支持与估计稳定性

1. 先验证实际 R5、模型残差、设计列的分布与影响；不要直接假定左尾指数、正态性或无限方差。
2. 对收益头报告原样本误差、梯度/影响或准确重拟合敏感性，识别哪些过去事件簇对后来参数和预测具有大影响。大平方误差占比不等于大参数影响，必须结合特征杠杆与收缩。
3. 历史事件簇删除/降权仅发生在每个当时已成熟的训练集，保持后续评价行情和极端亏损全部保留；该操作只用于影响诊断，不冒充可在事前知道坏数据的正式策略。
4. 区分影响来自目标值、训练尺度/样条节点还是交互乘积。固定变换检查与完整重拟合检查分别标明，不混为同一实验。
5. 报告19项输入与63列设计的相关结构、数值秩、Ridge有效自由度、L1非零系数、实际超出训练的交互列与联合状态支持。逐列位于min/max内不意味着联合状态在训练中充分出现。
6. 核查原Ridge目标为SSE + alpha*||beta||²。在标准化设计下，样本数变化可能改变固定alpha的相对正则力度；按实际各期样本、奇异值和选择结果评估，不凭alpha绝对数值称强或弱。
7. 保存 P4/P7 原内层所有候选得分，区分最强收缩端胜出、微小差别、数值并列；不能用再扩一轮网格来代替诊断。
8. Huber/MAE若作为后续挑战者，必须注明其在偏态分布下通常不再估计同一条件均值。不得删掉真实危机、温莎化评价收益、加正类权重后仍声称原概率已经校准。

### 输出

明确“大尾部主导错误”“维度/共线性导致估计不稳”“联合状态缺乏支持”“正则尺度或窗口变化”等各项是否被证据支持。稳健估计改变统计目标与提高同一目标估计质量，分开判断。

## D4：19项信息到底承担什么功能

不再以每个指标单独赚钱作为入选条件，也不以一次SHAP排名或单列删除作为因果证据。

1. 复用 P6 分组删除与交互诊断；由于E来自B/D，明确原始信息与派生列的区别，不重复已有结果。
2. 区分三个问题：当前状态描述、未来SVXY波动/损失信息、未来SVXY净收益信息。原R5/L5/Y10结果保留。
3. 可增加一个预先记录的预测诊断目标：与原可执行起点一致的未来五日SVXY日收盘对数收益平方均值。它是日线方差代理，不是高频已实现方差。只比较一个仅用近期自身波动的简约基准与一个受约束联合方法，不扫描模型库。
4. 若使用QLIKE，可用 log(v_hat)+v_observed/v_hat（预测严格为正）评价条件方差均值；预测正值处理要预先规定。收益头继续按其统计目标评价。不能把“会预测波动强度”直接晋升为收益择时有效。
5. 检查已有信息是否仅在特定、当时可定义的状态中提供条件增量。分组边界必须来自过去训练或提前规定；不按未来赚钱的日期反推状态。
6. 本轮不新增新闻、GEX、订单流、期权链或专有指数。若需要更快状态表示，先指出现有原始数据中被五日聚合丢失的具体信息，再另行提出最小表示修改。

### 输出

对家族或模型可报告：只描述当前、对风险强度有增量但对收益无增量、存在有待验证的局部交易信息、当前没有检测到增量。没有检测到不写成数学上证明所有未来都无用。

## D5：最多一个机制假说的有限反证（单独决定执行）

D1—D4结束后，先出不超过一页的假说比较，再提出一个主假说及一个最小干预。

例子：若证据指向门槛放大，冻结预测仅改变一个有成本/持仓状态依据的映射；若指向时效，核实更早信息可得性后更改一个时钟并重新训练；若指向估计不稳，保持时钟/目标/输入/映射，只改变一个估计或正则机制。

禁止一次更改损失、标签、因子、时钟和交易规则后把改进归因于其中一项。任何提高收益都必须同时报告相同日期的预测变化、成本、敞口、尾部损失和未改善的区间。不能以对M0的收缩直接等于M0来宣称发现新优势。

若假说被推翻，照实保留，不自动开始第二轮无上限搜索。若支持某机制，也只称对该机制的历史反证结果，不称新的独立实盘优势。
